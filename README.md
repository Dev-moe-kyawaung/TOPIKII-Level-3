# TOPIK II Level 3 · အပြည့်စုံဆုံး မြန်မာလေ့လာရေး

မြန်မာဘာသာဖြင့် TOPIK II Level 3 အတွက် အပြည့်စုံဆုံး သဒ္ဒါ ၆၀၊ ဝေါဟာရ ၁၅၀၊
စာမေးပွဲပုံစံများ၊ အရေးအသားနမူနာများ၊ နားထောင်ခြင်းနှင့် စာဖတ်ခြင်းဗျူဟာများ
ပါဝင်သော static GitHub Pages project။

## ပါဝင်သည့်အရာ

- သဒ္ဒါ ၆၀ ချက်: ပုံစံ၊ အဓိပ္ပါယ်၊ အသုံးပြုပုံ၊ နမူနာဝါကျ
- ဝေါဟာရ ၁၅၀ လုံး: မြန်မာဘာသာပြန်နှင့် ရှင်းလင်းချက်
- စာမေးပွဲပုံစံ: Listening, Writing, Reading အသေးစိတ်
- အရေးအသားနမူနာ: ပုဒ် ၄ ပုဒ်စလုံးအတွက် နမူနာ
- နားထောင်ခြင်းနှင့် စာဖတ်ခြင်းဗျူဟာများ
- အရေးကြီးသတိပြုရမည့်အချက်များ
- Search၊ category filter၊ bookmark နှင့် learned state
- Flashcard နှင့် ၁၅ ပုဒ်ပါ ဝေါဟာရ quiz
- CSV export နှင့် browser Print → Save as PDF

## Local တွင် ဖွင့်ရန်

`index.html` ကို browser ဖြင့် ဖွင့်ပါ။ Build သို့မဟုတ် npm install မလိုပါ။

## GitHub Pages တင်ရန်

1. Repository အသစ်တစ်ခု ဖန်တီးပါ။
2. ဤ project ဖိုင်အားလုံးကို repository root တွင် upload လုပ်ပါ။
3. GitHub → Settings → Pages သို့သွားပါ။
4. Source: Deploy from a branch ကို ရွေးပါ။
5. Branch: main၊ Folder: /(root) ကို ရွေးပြီး Save နှိပ်ပါ။
6. Pages ပေးသော URL ကို ဖွင့်ပါ။

## Content တိုးချဲ့ရန်

`data.js` ရှိ `GRAMMAR_TEXT` သို့မဟုတ် `VOCAB_TEXT` တွင်
format တူညီသော စာကြောင်းအသစ် ထည့်ပါ။ `|` သင်္ကေတကို
field ခွဲရန် သုံးထားသောကြောင့် content အတွင်း မထည့်ပါနှင့်။

## Level 3 အောင်မြင်ရန် အကြံပြုချက်

- နေ့စဉ် သဒ္ဒါ ၃ ချက်၊ ဝေါဟာရ ၁၅ လုံး စနစ်တကျ လေ့လာပါ
- အရေးအသားနမူနာများကို ကိုယ်တိုင်ရေးသားပြီး လေ့ကျင့်ပါ
- Listening အတွက် ကိုရီးယားရေဒီယို၊ podcast များကို နားထောင်ပါ
- Reading အတွက် ကိုရီးယားသတင်းစာ၊ blog များကို ဖတ်ရှုပါ
- စာမေးပွဲမတိုင်မီ ၂ ပတ်အလိုတွင် mock test များ ဖြေဆိုလေ့ကျင့်ပါ
